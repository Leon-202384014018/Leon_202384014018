# To-Do LIST· Today

A simple to-do list web page for the Senior Capstone Project.

## What it does 

- Grouped task list: Morning / Afternoon / Done sections
  
- Priority colors on the left edge of each card — pink = High, yellow = Medium, green = Low
  
- Add a task with a priority selector (High / Medium / Low) use AI
  
- Tasks are saved in the browser, so they stay after refresh
  
- Today's date is filled in automatically
  

## How to use 

 Open `index.html` in a browser.
   
 Type a task, pick a priority, click **Add**.
   
 New tasks appear at the top under "Today · 今天".
