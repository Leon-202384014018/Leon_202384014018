# To-Do — Focus Board

A minimal to-do list web page for the Senior Capstone Project.
A large circular focus clock sits in the middle, with today's date and a task list below.
一个极简黑白风的待办清单网页：中间是圆形专注时钟，下方是日期与任务列表。

## What it is

- White, monochrome design: black text, thin dividers, lots of whitespace
- Big circular clock showing `25:00 FOCUS` as the centrepiece
- Task list with reminder times and priority dots (black = high, grey = medium / low)
- Static interface design only — no interaction yet; JavaScript features come in the final version

## Tech stack

HTML5 + CSS3, plus a small read-only script for the live clock. One file, no frameworks, no build step.
